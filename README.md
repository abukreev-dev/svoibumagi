# Свои бумаги

Self-hosted инвестиционный учёт по файлам брокерских отчётов. Исходный код открыт по лицензии [GPL-3.0-or-later](LICENSE). Сервис рассчитан на одного владельца и хранит отчёты, исходные строки, журнал операций и решения по импорту в его собственной SQLite-базе.

## Как это работает

1. Создайте локальный счёт для брокера и загрузите отчёт.
2. Проверьте предпросмотр: сделки, движения денег, позиции, остатки, контрольные суммы, неизвестные строки и возможные повторы.
3. Подтвердите или отклоните импорт. Каждая проведённая операция сохраняет связь с исходным файлом и строкой.
4. Смотрите состояние портфеля и выгружайте CSV. При неполной истории или недоступной сверке сервис показывает `unavailable` и причину вместо расчётного результата.

Есть адаптеры для проверенных вариантов HTML Сбера и XLS/XLSX Альфа-Инвестиций. Поддержка этих форматов остаётся экспериментальной: отчёты других периодов и новых версий брокерских шаблонов требуют отдельной сверки. Повторные и перекрывающиеся файлы проходят проверку на дубли и конфликты. Для расчётов используются десятичная арифметика, FIFO и XIRR; полноценная доходность доступна только после подтверждения полной истории счёта и оценки активов.

## Быстрый запуск

Нужны Python 3.12+ и Docker Compose. Получите хеш пароля интерактивно, без записи пароля в командную строку:

```bash
python3 -m venv .venv
.venv/bin/pip install -e '.[test]'
.venv/bin/python -m svoibumagi hash-password
```

Сохраните полученный `scrypt:` хеш в локальный `.env`:

```dotenv
SVOIBUMAGI_PASSWORD_HASH=scrypt:...
SVOIBUMAGI_HOST_PORT=18080
```

Запустите приложение за собственным HTTPS reverse proxy:

```bash
docker compose --env-file .env up -d --build
```

Порт Compose опубликован только на `127.0.0.1`; перенаправьте на него запросы с TLS и откройте сайт через HTTPS. Для разработки на одном компьютере есть `compose.local-http.yaml`, который разрешает сессию по HTTP **только при локальном доступе**:

```bash
docker compose -f compose.yaml -f compose.local-http.yaml --env-file .env up -d --build
```

Откройте `http://127.0.0.1:18080/`. Подробности запуска, резервного копирования и восстановления: [эксплуатация](docs/operations.md). Конфигурация действующего экземпляра на `ddl` приведена [отдельно](docs/deploy-ddl.md) как пример, без его данных и секретов.

## Текущее состояние

На действующем HTTPS-экземпляре проверен частичный импорт за 2025 год: восемь месячных HTML Сбера и один годовой XLS/XLSX Альфы, два счёта, 1 842 проведённых события. Их количества и доступные брокерские сверки совпали с закрытыми независимыми контрольными таблицами. Повторный импорт одного файла распознал 136 дублей и не добавил событий. CSV, резервная копия, перезапуск контейнера и целостность SQLite проверены. Личные файлы и результаты сверки не входят в репозиторий.

Эта проба **не подтверждает полноту портфеля**: остальные отчёты будут загружены владельцем позднее. В отдельных отчётах отсутствуют снимки позиций; соответствующие проверки остались недоступными. Из-за неполной истории FIFO и XIRR для загруженных счетов сейчас недоступны. Поддержка варианта отчёта определяется по предпросмотру и контрольным суммам, а не только по расширению файла.
