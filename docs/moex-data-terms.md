# Условия использования данных MOEX ISS

**Срез: 10 октября 2026 года. Статус для V1: доступ не подтверждён, запросы ISS выключены по умолчанию.**

Официальная [страница ISS](https://www.moex.com/a2193) различает данные по подписке и данные с задержкой без подписки. Там же Биржа указывает, что полученная через ISS информация доступна для ознакомления, а иное использование требует договора. Отсутствие технической авторизации для задержанных данных само по себе не даёт права автоматически использовать их для расчётов приложения.

Официальная [страница индивидуального использования](https://www.moex.com/ru/products/personal) требует оформить заявку и принять публичную оферту для просмотра и выгрузки данных, включая доступ через API. При этом [обзор способов получения данных](https://www.moex.com/s3503) прямо относит к индивидуальному использованию режим **без автоматизированной выгрузки**. Сам факт, что API указан среди способов получения, не подтверждает разрешение на автоматическое накопление котировок локальной программой. [Порядок использования биржевой информации](https://www.moex.com/ru/datapolicy) отдельно описывает договоры для автоматической обработки данных в системах бэк-офиса и других режимах Non-display.

**Вывод для проекта:** автоматическое получение цен ISS для оценки портфеля и XIRR выходит за рамки простого просмотра данных в интерфейсе Биржи. Из опубликованных страниц нельзя однозначно определить, какой договор нужен для частного self-hosted приложения, сохраняющего задержанные или исторические цены и не распространяющего сами данные. До письменного разъяснения Биржи или подтверждённого договора оператор оставляет `SVOIBUMAGI_MOEX_ISS_ENABLED=0`. Пользователь может вводить ручную цену с датой и указанием собственного разрешённого источника.

Вопросы для разъяснения Бирже, **не отправлены**:

1. Какой тип доступа и договор применим к одному частному пользователю, если локальная программа автоматически запрашивает через ISS задержанные и исторические цены акций и облигаций, сохраняет их в своей SQLite и рассчитывает стоимость личного портфеля и XIRR?
2. Разрешено ли распространять исходный код такого клиентского приложения под GPL, если код не содержит биржевых данных, а каждый оператор отдельно оформляет нужный доступ?
3. Требуются ли отдельные условия для исторических цен, НКД, номинала облигаций и автоматического поиска бумаги по ISIN?

Настройка доступа, акцепт оферты и договор остаются действиями владельца. Кодовый переключатель и успешный HTTP-ответ ISS не подтверждают право использования данных.
